# Learning Resource Request Feature

## Overview
This feature allows a student to post a request for learning resources on a specific topic so that peers in the community can recommend suitable resources.

## User Story
As a student, I want to post a request for learning resources on a specific topic so that peers can recommend suitable resources.

## Proposed Functionality
- A logged-in student can create a "Resource Request" post specifying a topic, a course/subject tag, and a short description of what they need.
- Other students can respond to the request with recommended resources (links, book titles, videos, notes).
- The original poster can mark one response as the "Accepted Recommendation" once satisfied.
- Requests can be searched and filtered by topic or course tag.

## Acceptance Criteria
- A logged-in student can create a resource request with a title, topic tag, and description.
- Peers can add comment-based recommendations to a request.
- The original poster can mark one recommendation as accepted.
- Requests are listed and searchable by topic tag.
